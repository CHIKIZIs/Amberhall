# Amberhall — мод для Minecraft (Fabric 1.21.1)

Добавляет янтарь из глубин Эмберхолла:
- **Янтарная руда** — генерируется в Верхнем мире на высотах от −16 до 80, ломается киркой не ниже железной; даёт 1–2 янтаря (удача увеличивает добычу, шёлковое касание даёт саму руду);
- **Янтарь** — самоцвет; плавится в печи и в плавильне;
- **Янтарный блок** — из 9 янтарей, светится (уровень 8);
- **Янтарный меч** и **Янтарная кирка** — между железом и алмазом по скорости, 400 прочности, высокое зачарование;
- вкладка творческого режима «Эмберхолл», русский и английский языки.

## Сборка

Нужны JDK 21 и Gradle 8.10+ (или IntelliJ IDEA с поддержкой Gradle).

```
gradle wrapper      # один раз, создаст gradlew
./gradlew build     # готовый мод: build/libs/amberhall-1.0.0.jar
./gradlew runClient # запустить Minecraft с модом для проверки
```

Установка: положите `amberhall-1.0.0.jar` и [Fabric API](https://modrinth.com/mod/fabric-api) в папку `mods` профиля Fabric Loader 1.21.1.

Если Gradle не находит `fabric_version`, откройте `gradle.properties` и подставьте актуальную версию Fabric API для 1.21.1 (список на странице Fabric API на Modrinth).
