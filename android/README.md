# «Зачёт» — подготовка к ЕГЭ для Android

`zachet.apk` — готовый установочный файл. Внутри: 16 предметов ЕГЭ, тренировки по темам, тесты, пробные варианты, блиц, карточки, работа над ошибками, уровни, лиги и рейтинг друзей по кодам. Внутри то же веб-приложение из `../sochinenie`, открытое во встроенном WebView. Работает без интернета, шрифты лежат в `app/assets/fonts`. Интернет нужен только для поиска ошибок: текст отправляется в бесплатный сервис LanguageTool (api.languagetool.org).

Проверка сочинения из тетради: текст переносится через Google Объектив («Поделиться» → «Зачёт» или «Копировать» → «Вставить из буфера»). Слова, абзацы, предложения, штампы, повторы и подсказки по запятым приложение считает само.

## Установка
1. Скачай `zachet.apk` на телефон.
2. Открой файл и разреши установку из этого источника, если Android спросит.
3. Нажми «Установить».

Прогресс (отметки, сочинения) хранится внутри приложения и пропадёт, если его удалить.

## Пересборка
```bash
ANDROID_SDK=/путь/к/sdk KEYSTORE=~/keys/zachet.jks KEYSTORE_PASS=... \
VERSION_CODE=2 VERSION_NAME=1.1 ./build.sh
```
Нужен Android SDK: `build-tools;35.0.0` и `platforms;android-34`. При обновлении увеличивай `VERSION_CODE`.
Ключ подписи в репозиторий не кладётся. Если ключа нет, скрипт создаст новый, но тогда новую версию
получится поставить только после удаления старой.
