# Pixel Survival: Lost Lands

2D-игра про выживание на острове: пиксельная графика, крафт, строительство, ферма, подземелья и боссы. Только для ПК.

## Запуск
Откройте `index.html` через любой локальный веб-сервер, например `npx serve .` или `python3 -m http.server`, затем перейдите на `http://localhost:8000`.

## Управление
- WASD — ходьба, Shift — бег.
- Мышь — прицел. ЛКМ — атака (удерживайте для сильного удара), ПКМ — блок.
- Пробел — рывок.
- E — взаимодействие, Q или F — применить предмет.
- 1–8 и колесо мыши — выбор предмета.
- I — инвентарь, C — крафт, B — стройка, J — задания, N — навыки, M — карта, Esc — меню.

## Миры и сиды
Кнопка «Новая игра» открывает окно с названием мира и сидом. Сид — это число или любой текст; одинаковый сид всегда даёт одинаковый мир. Сид текущего мира показан в настройках.

## Сетевая игра (основа)
- **Хост.** В настройках нажмите «Открыть мир для друзей» и сообщите друзьям код комнаты.
- **Гость.** В главном меню выберите «Подключиться к другу» и введите код.
- **Без сервера.** Оставьте адрес сервера пустым — тогда игра идёт между вкладками одного браузера. Так удобно проверять.
- **Через интернет.** Запустите ретранслятор: `cd server && npm install && npm start`. Затем хост и гости вводят адрес `ws://IP_СЕРВЕРА:8787`.

Сейчас синхронизируются:
- игроки: положение, внешний вид, ники;
- изменения мира: рубка, сбор, постройки, двери, сундуки, грядки, рычаги.

Пока не синхронизируются:
- существа — у каждого игрока свои;
- выпавшие на землю предметы.

Гость не сохраняет мир хоста к себе.
