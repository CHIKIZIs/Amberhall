# 3D Сканер для Android

Приложение сканирует предметы, комнаты и территорию камерой телефона и превращает
результат в цветную 3D-модель — аналог LiDAR-сканеров на iPhone, но для Android.

## Как это работает

LiDAR есть далеко не на всех Android-телефонах, поэтому приложение использует
**ARCore Depth API** от Google. Он строит карту глубины:

* обычной камерой — по движению телефона (depth-from-motion), работает на сотнях моделей;
* используется «сырая» глубина с картой уверенности (ненадёжные точки отбрасываются),
  каждая оценка глубины учитывается ровно один раз;
* ToF-датчиком глубины, если он есть в телефоне (приложение выбирает его автоматически).

Дальше всё как в профессиональных сканерах:

0. **Область сканирования** (режимы «Предмет» и «Обычный») — рамка ставится на объект
   в центре экрана, размер меняется щипком. Всё вне рамки игнорируется.
1. **Отслеживание** — ARCore знает положение телефона в пространстве в каждый момент.
2. **Слияние глубины (TSDF)** — каждая карта глубины вписывается в общий разреженный
   воксельный объём (блоки 8×8×8 вокселей создаются только около поверхностей).
   Много наблюдений одной точки усредняются, и шум пропадает. Цвет берётся из камеры.
3. **Построение сетки (Surface Nets)** — из объёма извлекается гладкая треугольная
   сетка с цветами вершин, мелкий «мусор» удаляется.
4. **Экспорт** — GLB (glTF 2.0), OBJ (с цветами вершин) и PLY.

Всё считается прямо на телефоне, без интернета и облака.

## Режимы

| Режим    | Детализация | Дальность | Для чего |
|----------|-------------|-----------|----------|
| Предмет  | 6 мм        | до 1,2 м  | вещи на столе, обувь, игрушки (стол убирается автоматически) |
| Обычный  | 1,2 см      | до 3 м    | мебель, люди, уголок комнаты |
| Комната  | 3 см        | до 5 м    | комната целиком |
| Улица    | 5 см        | до 8 м    | двор, фасады, территория |

## Советы для хорошего скана

* Двигайтесь **медленно** и плавно, обходите объект со всех сторон (полный круг, сверху и сбоку).
* Для предметов держите телефон в 30–80 см. Ближе 30 см глубина почти не определяется.
* Предмет лучше класть на поверхность с рисунком (газета, ковёр) — так телефону легче
  понять своё положение. Чёрные матовые и однотонные предметы — самые сложные.
* Нужен хороший свет; однотонные белые стены, зеркала, стекло и чёрные глянцевые
  поверхности сканируются плохо (это ограничение любой камеры без LiDAR).
* Можно ставить на паузу (красная кнопка) и продолжать.

## Требования

* Android 8.0+ и телефон с поддержкой **ARCore Depth API**
  (список: <https://developers.google.com/ar/devices>, колонка «Supports Depth API»).
* Установленные «Сервисы Google Play для AR» (приложение предложит установить).

## Сборка

```bash
cd scanner3d-android
./gradlew assembleRelease     # APK: app/build/outputs/apk/release/app-release.apk
./gradlew testDebugUnitTest   # тест реконструкции на синтетической сфере
```

Или откройте папку `scanner3d-android` в Android Studio. GitHub Actions собирает APK
автоматически (workflow «Android 3D Scanner APK», артефакт `3d-scanner-apk`).

APK подписан отладочным ключом — подходит для установки на свой телефон, но не для Google Play.

## Структура кода

* `recon/TsdfVolume.kt` — слияние глубины и построение сетки (ядро сканера)
* `recon/Mesh.kt` — сетка, нормали, удаление шумовых островков
* `io/MeshIO.kt` — запись/чтение PLY, OBJ, GLB
* `ScanActivity.kt` — экран сканирования (ARCore, захват кадров)
* `ViewerActivity.kt` — просмотр модели и экспорт
* `render/` — OpenGL ES отрисовка камеры, облака точек и сетки
