Bat Colors — ресурспак для Minecraft 1.21.1

Добавляет 10 расцветок летучей мыши: классическая, теневая, альбинос, багровая, океанская, лесная, янтарная, фиолетовая, вишнёвая, ледяная.
Цвет у каждой мыши случайный, от биома не зависит. Исключение: в ледяных биомах мыши всегда морозные (и только там).

Для случайных расцветок нужен мод Entity Texture Features (ETF) для Fabric 1.21.1 или OptiFine.
Без них Minecraft не умеет выбирать текстуру моба случайно: тогда все мыши будут обычными.
